# 🛒 Retail Sales Analysis Using SQL

## 📌 Project Overview

The **Retail Sales Analysis** project focuses on analyzing retail transaction data using SQL to uncover valuable business insights. The project involves data cleaning, exploratory data analysis (EDA), and answering real-world business questions related to sales performance, customer behavior, and product categories.

By leveraging SQL queries, this project transforms raw sales data into actionable insights that can help businesses improve decision-making, optimize inventory management, and enhance customer engagement.

---

## 🎯 Objectives

- Create and manage a retail sales database.
- Clean and validate sales data.
- Perform exploratory data analysis (EDA).
- Analyze customer demographics and purchasing behavior.
- Identify top-performing product categories.
- Discover sales trends and seasonal patterns.
- Generate business insights using SQL queries.

---

## 🗄️ Database Schema

### Table: `retail_sales`

| Column Name | Description |
|------------|-------------|
| transactions_id | Unique transaction ID |
| sale_date | Date of transaction |
| sale_time | Time of transaction |
| customer_id | Unique customer ID |
| gender | Customer gender |
| age | Customer age |
| category | Product category |
| quantity | Quantity purchased |
| price_per_unit | Price per unit |
| cogs | Cost of Goods Sold |
| total_sale | Total transaction value |

## 📈 Key Insights

### 👥 Customer Insights
- A small group of customers contributes significantly to total revenue.
- Loyal customers make repeated purchases and are valuable for retention strategies.
- Different age groups show different purchasing preferences across categories.

### 🛍️ Product Insights
- Certain categories consistently generate higher sales revenue.
- Popular categories attract more unique customers.
- High-performing categories should receive greater inventory and marketing focus.

### 💰 Sales Insights
- Several transactions exceed ₹1000, indicating premium purchases.
- Monthly sales patterns reveal seasonal demand fluctuations.
- Peak sales periods provide opportunities for targeted promotions.

### ⏰ Operational Insights
- Customer shopping behavior varies throughout the day.
- Sales shift analysis helps optimize staffing and store operations.
- Understanding peak shopping hours improves resource allocation.
